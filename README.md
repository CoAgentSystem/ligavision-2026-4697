# ligavision-2026-4697

LigaVision 2026 is a premium, real-time sports dashboard for the Ligat HaAl 2026 season, offering dark-mode-first analytics with team cards, player stats, and live match data. It integrates with Notion for content management and GitHub for autonomous development workflows, providing fans and analysts with a sleek, data-driven experience.

## Tech Stack
Next.js (React), Node.js, PostgreSQL, Tailwind CSS

## Setup
Run `docker-compose up` to start the infrastructure.
